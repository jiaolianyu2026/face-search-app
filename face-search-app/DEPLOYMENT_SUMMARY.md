## 🚀 使用部署包

### 创建部署包

```batch
# 1. 运行打包脚本
scripts\package.bat

# 2. 生成的文件
deploy\FaceRecognitionSearch_v1.0.0_YYYYMMDD\     # 文件夹
deploy\FaceRecognitionSearch_v1.0.0_YYYYMMDD.zip  # 压缩包
```

### 测试部署包

```batch
# 运行测试脚本
scripts\test_package.bat

# 检查测试结果
# - 文件完整性
# - 脚本可执行性
# - 目录结构
```

### 分发部署包

1. **压缩包方式**
   - 分发 `FaceRecognitionSearch_v1.0.0_YYYYMMDD.zip`
   - 用户解压后运行 `scripts\install.bat`

2. **文件夹方式**
   - 复制整个 `FaceRecognitionSearch_v1.0.0_YYYYMMDD` 文件夹
   - 用户直接运行 `scripts\install.bat`
