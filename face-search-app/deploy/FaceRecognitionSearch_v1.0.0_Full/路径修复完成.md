## 📊 技术细节

### 路径解析原理

#### %~dp0 的含义
- `%0` = 脚本完整路径（如 `C:\App\scripts\start.bat`）
- `%~d0` = 驱动器号（如 `C:`）
- `%~p0` = 路径（如 `\App\scripts\`）
- `%~dp0` = 驱动器 + 路径（如 `C:\App\scripts\`）

#### 定位应用根目录
```batch
set SCRIPT_DIR=%~dp0           # C:\App\scripts\
cd /d "%SCRIPT_DIR%.."         # 切换到 C:\App\
set APP_ROOT=%CD%              # 获取当前目录 C:\App
```

#### 使用绝对路径
```batch
# 错误（相对路径）
if exist backend\venv_new (...)

# 正确（绝对路径）
if exist "%APP_ROOT%\backend\venv_new" (...)
```
