# 人脸识别搜索应用 - 安装指南

## 📦 完整安装包说明

此安装包包含所有运行依赖，**无需安装 Python 和 Node.js**，解压即可使用！

---

## 🚀 快速安装（3 步）

### 步骤 1：解压安装包

将整个文件夹解压到目标位置，例如：
```
C:\FaceRecognitionSearch
```

**重要提示**：
- 路径中不要包含中文字符
- 确保有足够的磁盘空间（至少 2GB）
- 确保对该目录有读写权限

### 步骤 2：验证安装包（可选）

双击运行：
```
scripts\check.bat
```

这会检查安装包是否完整。如果显示"✓ 安装包完整"，继续下一步。

### 步骤 3：启动应用

双击运行：
```
scripts\start.bat
```

等待 5-10 秒，两个命令行窗口会自动打开：
- 后端服务窗口（Flask）
- 前端服务窗口（Vite）

浏览器会自动打开应用页面：http://localhost:3000

**注意**：首次启动可能需要 10-15 秒，请耐心等待

### 步骤 3：开始使用

1. 上传包含人脸的图片
2. 等待人脸检测完成
3. 输入搜索文件夹路径
4. 查看匹配结果

## ❓ 常见问题

### Q1: 双击 start.bat 后提示"虚拟环境不存在"？

**A**: 
1. 首先运行 `scripts\check.bat` 检查安装包完整性
2. 如果显示 venv_new 不存在，说明解压不完整
3. 重新解压安装包，确保解压到一个空文件夹
4. 解压时不要中断，等待完全解压完成
5. 确保有足够的磁盘空间（至少 2GB）

### Q2: 双击 start.bat 后没有反应？

**A**: 
1. 右键点击 `start.bat`，选择"以管理员身份运行"
2. 检查是否有杀毒软件阻止
3. 查看是否有防火墙提示，选择"允许访问"

### Q3: 提示"端口被占用"？

**A**:
1. 运行 `scripts\stop.bat` 停止其他服务
2. 或者重启电脑
3. 检查是否有其他程序占用 3000 或 5000 端口

### Q4: 浏览器无法访问 localhost:3000？

**A**:
1. 等待 10-15 秒让服务完全启动
2. 手动在浏览器输入：http://localhost:3000
3. 尝试使用 http://127.0.0.1:3000
4. 检查防火墙设置

### Q5: 人脸检测失败？

**A**:
1. 确保图片清晰且包含人脸
2. 支持的格式：JPG, PNG, WebP
3. 文件大小限制：10MB
4. 查看后端日志：`backend\app.log`

### Q6: 如何卸载？

**A**:
1. 运行 `scripts\stop.bat` 停止服务
2. 直接删除整个安装文件夹即可
3. 无需卸载任何系统组件

## 🔧 高级配置

### 修改端口

如果需要修改默认端口，编辑以下文件：

**后端端口**（默认 5000）：
- 编辑 `backend/app.py`
- 找到 `app.run(host='0.0.0.0', port=5000)`
- 修改 `port=5000` 为其他端口

**前端端口**（默认 3000）：
- 编辑 `frontend/vite.config.js`
- 修改 `server.port` 配置

### 查看日志

后端日志位置：`backend\app.log`

查看命令：
```batch
type backend\app.log
```

实时监控：
```powershell
Get-Content backend\app.log -Tail 20 -Wait
```
