# 故障排查指南

## 问题：上传图片后人脸识别失败

### 症状
- 第一次上传图片成功，但人脸识别失败
- 第二次上传时报错"上传失败，请检查网络连接"

### 根本原因
后端服务在处理人脸检测时崩溃或停止运行。

### 解决方案

#### 1. 检查后端服务状态
打开终端，运行：
```powershell
# 检查后端进程是否在运行
# 如果看到 "running" 表示正常，"stopped" 表示已停止
```

#### 2. 重启后端服务
如果后端停止，重新启动：
```powershell
cd backend
.\venv_new\Scripts\python.exe app.py
```

#### 3. 查看错误日志
检查后端日志文件：
```powershell
cd backend
Get-Content app.log -Tail 50
```

### 常见问题

#### 问题 1: 后端频繁崩溃
**可能原因**：
- 内存不足
- 图片文件过大或格式异常
- face_recognition 库加载模型失败

**解决方法**：
1. 确保系统有足够内存（建议 4GB+）
2. 使用较小的测试图片（< 5MB）
3. 检查图片格式是否正确（JPEG、PNG、WebP）

#### 问题 2: 人脸检测速度慢
**可能原因**：
- 图片分辨率过高
- CPU 性能不足

**解决方法**：
1. 使用分辨率适中的图片（建议 1920x1080 以下）
2. 等待检测完成（首次加载模型可能需要 10-30 秒）

#### 问题 3: 无法检测到人脸
**可能原因**：
- 图片中没有清晰的人脸
- 人脸角度过大
- 光线太暗或太亮

**解决方法**：
1. 使用包含清晰正面人脸的图片
2. 确保人脸占图片的合理比例
3. 使用光线良好的照片

### 服务管理

#### 启动服务
```powershell
# 启动后端（终端 1）
cd backend
.\venv_new\Scripts\python.exe app.py

# 启动前端（终端 2）
cd frontend
npm run dev
```

#### 停止服务
- 在运行服务的终端中按 `Ctrl+C`

#### 查看服务状态
- 后端：访问 http://localhost:5000（应该看到 404 页面，表示服务运行中）
- 前端：访问 http://localhost:3000（应该看到应用界面）

### 性能优化建议

1. **首次使用**：首次检测人脸时，face_recognition 需要加载模型，可能需要 10-30 秒
2. **后续使用**：模型加载后，检测速度会明显提升
3. **图片大小**：建议使用 2-5MB 的图片，既保证质量又不影响性能
4. **并发限制**：避免同时上传多张图片，等待当前图片处理完成
