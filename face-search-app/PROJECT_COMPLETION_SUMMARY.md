## 🚀 快速启动指南

### 前提条件
- ✅ Python 3.14+ 已安装
- ✅ Node.js 20+ 已安装
- ✅ 后端依赖已安装
- ⚠️ 前端依赖需要安装

### 启动步骤

#### 1. 启动后端服务

```powershell
# 打开终端 1
cd backend
venv\Scripts\activate
python app.py
```

后端运行在：**http://localhost:5000**

#### 2. 安装前端依赖（首次运行）

```powershell
# 打开新的终端 2（重要：必须是新终端）
cd frontend
npm install
```

#### 3. 启动前端服务

```powershell
# 在终端 2 中继续
npm run dev
```

前端运行在：**http://localhost:3000**

#### 4. 访问应用

在浏览器中打开：**http://localhost:3000**
