# 人脸识别搜索应用 - 使用指南

## 快速开始

### 1. 启动服务

**前端**（已启动）：
```
访问 http://localhost:3000
```

**后端**（已启动）：
```
运行在 http://localhost:5000
```

### 2. 使用流程

#### 步骤 1：上传图片
1. 点击"选择图片"或拖拽图片到上传区域
2. 支持格式：JPG, PNG, WebP
3. 文件大小限制：10MB

#### 步骤 2：检测人脸
1. 上传成功后自动开始检测
2. 等待 3-5 秒（取决于图片大小）
3. 显示检测到的人脸数量和位置

#### 步骤 3：选择目标人脸
1. 如果检测到多个人脸，点击选择要搜索的人脸
2. 如果只有一个人脸，自动选中
3. 点击"确认选择"

#### 步骤 4：开始搜索
1. 输入搜索文件夹路径（例如：`D:\AI_workspace\忆颜图谱`）
2. 可选：调整相似度阈值（默认 0.6）
3. 点击"开始搜索"

#### 步骤 5：查看结果
1. 实时显示搜索进度
2. 完成后显示所有匹配的人脸
3. 按相似度从高到低排序
4. 可以导出匹配的图片

## 常见问题

### Q1: 检测失败怎么办？
**A**: 
- 确保图片包含清晰的人脸
- 尝试使用较小的图片（< 2MB）
- 检查后端日志：`backend/app.log`

### Q2: 搜索很慢怎么办？
**A**:
- 大图片需要更长时间处理
- 文件夹中图片越多，搜索越慢
- 可以降低相似度阈值减少匹配数量

### Q3: 找不到匹配结果？
**A**:
- 降低相似度阈值（如 0.5）
- 确保搜索文件夹中有相似的人脸
- 检查图片质量和光照条件

### Q4: 后端崩溃了怎么办？
**A**:
```powershell
# 重启后端
cd backend
.\venv_new\Scripts\python.exe app.py
```

## 技术细节

### 相似度阈值说明

| 阈值 | 说明 | 适用场景 |
|-----|------|---------|
| 0.9-1.0 | 非常相似 | 同一个人的不同照片 |
| 0.7-0.9 | 较为相似 | 可能是同一个人 |
| 0.6-0.7 | 有些相似 | 需要人工确认 |
| < 0.6 | 不太相似 | 可能不是同一个人 |

### 支持的图片格式

- **JPEG/JPG**：最常用，兼容性好
- **PNG**：支持透明背景
- **WebP**：现代格式，文件更小

### 性能参考

| 图片尺寸 | 文件大小 | 检测时间 |
|---------|---------|---------|
| 800x600 | < 200KB | 1-2 秒 |
| 1920x1080 | < 500KB | 2-3 秒 |
| 4096x1808 | 1.8MB | 3-5 秒 |
