# 实现计划：人像库管理功能

## 概述

本实现计划将人像库管理功能分解为增量式的编码任务。每个任务都建立在前面的任务之上，最终集成所有组件。实现分为后端（Python/Flask）和前端（React）两部分，优先实现核心后端功能，然后构建前端界面。

- [ ] 5. 实现人像库 API 端点
  - [ ] 5.1 在 `backend/app.py` 中添加 API 端点
    - `POST /api/library/faces`: 保存人像到库
      - 接收 imageId, faceId, name
      - 从 detection_cache 获取人像特征
      - 生成缩略图
      - 调用 FaceLibraryModule.saveFace
      - 返回保存的人像信息
    - `GET /api/library/faces`: 获取所有库人像
      - 支持 sortBy 和 search 查询参数
      - 返回人像列表（不包含特征向量）
    - `GET /api/library/faces/{faceId}`: 获取单个人像详情
      - 返回完整人像信息（包含特征向量）
    - `PUT /api/library/faces/{faceId}`: 更新人像名称
      - 接收新名称
      - 调用 FaceLibraryModule.updateFace
    - `DELETE /api/library/faces/{faceId}`: 删除人像
      - 调用 FaceLibraryModule.deleteFace
    - `GET /api/library/faces/{faceId}/thumbnail`: 获取缩略图
      - 返回缩略图图片文件
    - _需求: 6.1, 6.2, 6.3, 6.4, 6.5, 6.6_

  - [ ] 5.2 实现 API 输入验证和错误处理

    - 使用现有的错误处理器（ValidationError, NotFoundError, ServiceError）
    - _需求: 6.7, 6.8_
